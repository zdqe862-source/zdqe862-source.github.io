# 极简 GitHub Pages 网站

本版本包含：
- 极简深色空白页面
- `assets/background.mp3` 背景音乐，循环播放
- 音量默认设为 18%
- 不显示播放器、按钮、文字或导航
- 不依赖 Jekyll 主题或第三方 CDN

## 替换仓库内容

1. 建议先在 GitHub 仓库页面下载一份原仓库 ZIP 作为备份。
2. 解压本 ZIP。
3. 将解压后的 `index.html`、`assets/` 和 `.nojekyll` 上传到仓库根目录。
4. 如果你确定不再需要旧博客，可以再删除旧主题文件。
5. 保留仓库的 GitHub Pages 设置；如果 Pages 原本从 `main` 分支的根目录发布，通常不需要改设置。
6. 等待 GitHub Pages 部署完成后，打开网站测试。

## 音频自动播放说明

浏览器可能阻止带声音的自动播放，尤其是 iPhone Safari。页面会先尝试自动播放；若被拦截，则在访客第一次触摸、点击或按键时静默启动音乐。页面不会显示播放按钮。

音量可在 `index.html` 中修改：
`audio.volume = 0.18;`

注意：本版本是单页极简网站。若以后增加页面并希望音乐跨页面不中断，需要改成单页导航或其他持久播放方案。
